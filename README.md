# Sistema de Gestión para Taller Mecánico

Proyecto de Programación II, Universidad Mariano Gálvez de Guatemala. Grupo No. 6.

Aplicación de escritorio en Java con base de datos MySQL.

## Cómo ejecutarlo

1. Tener la base de datos `taller_mecanico` creada en MySQL.
2. Revisar los datos de conexión en `config/conexion.properties`.
3. Abrir el proyecto en NetBeans y ejecutarlo con F6.
4. Entrar con el usuario `admin` y la contraseña `admin123`.
